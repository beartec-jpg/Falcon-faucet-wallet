## After you generate

1. Save with the exact GitHub filename above  
2. Overwrite files under `assets/images/...`  
3. If switching SVG→PNG, update `src` in `index.html`  
4. Optional: add `class="assets-final"` on `<body>` to hide “Replace:” badges
